# Project Overview

## Scenario

SecureBank is a fictional online banking platform providing:

- User Registration
- Login
- Money Transfers
- Bill Payments
- Transaction History
- File Uploads
- Notifications

The goal is to identify potential security risks before implementation.

---

## Threat Modeling Goals

- Understand data movement
- Identify trust boundaries
- Identify sensitive assets
- Discover threats
- Recommend mitigations
