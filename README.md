# SecureBank-Threat-Modeling---Level-1-DFD


A practical threat modeling exercise for a fictional digital banking platform.

## Objectives

This project demonstrates how to perform threat modeling during the design phase of the Software Development Life Cycle (SDLC).

The assessment follows an iterative approach:

- System Scoping
- Data Flow Diagram (DFD)
- Trust Boundary Identification
- Asset Identification
- STRIDE Analysis
- Abuse Cases
- Attack Trees
- Risk Assessment
- Mitigation Planning
